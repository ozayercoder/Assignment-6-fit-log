## 📖 About The Project

Briefly explain:
- This is a workout selector website
- I practice Next JS routing, React context API and many more interesting topics via this project.

---

## ✨ Features

- You can Add any workout to todays plan
- You can save any workout for later
- You can remove and mark any workout as completed in My Plan page
- You can view full details of each workout
- You can select maximum 5 workout to your todays plan
- The website is fully resposive
- It has cool user interface
